## 1. Artificial Intelligence
Artificial Intelligence (AI) is a field of computer science focused on creating machines and software that can perform tasks that normally require human intelligence, such as understanding language, recognizing images, solving problems, learning, and making decisions.

Examples include voice assistants, recommendation systems, face recognition, chatbots, and navigation apps.

## 2. Machine Learning
Machine Learning (ML) is a subset of AI. It allows computers to learn patterns from data and make predictions or decisions without a programmer writing a separate rule for every situation.

Example: An email service can learn from examples of spam and non-spam emails to identify unwanted messages.

## 3. Difference between AI, ML, and Deep Learning
- **AI:** The broad field of making computer systems perform tasks that appear intelligent.
- **ML:** A part of AI in which systems learn patterns from data.
- **Deep Learning:** A part of ML that uses multi-layered neural networks to learn complex patterns.

**Relationship:** Deep Learning is a subset of Machine Learning, and Machine Learning is a subset of Artificial Intelligence.

| Term | Meaning | Example |
|---|---|---|
| AI | Broad field of intelligent computer systems | Voice assistant |
| ML | Learns patterns from data | Email spam detection |
| Deep Learning | Uses deep neural networks | Image and speech recognition |

## 4. Real-world applications of AI
1. **Healthcare:** Supports analysis of medical images and helps clinicians identify patterns.
2. **Education:** Offers personalized practice, tutoring support, and learning recommendations.
3. **Banking:** Helps identify unusual transactions and possible fraud.
4. **Transportation:** Supports route planning, traffic prediction, and driver-assistance systems.
5. **E-commerce:** Recommends products based on browsing and purchase patterns.
6. **Agriculture:** Can help monitor crops, detect plant disease, and estimate yields.

AI tools support people; important decisions should still be checked by qualified humans.

## 5. Installing Python
1. Visit https://www.python.org/downloads/.
2. Download a stable Python 3 release for your operating system.
3. Run the installer. On Windows, select **Add Python to PATH** if that option appears.
4. Complete the installation.
5. Open Command Prompt or Terminal and check with `python --version` (on some systems use `python3 --version`).
6. You can write programs in IDLE, Visual Studio Code, or an online Python editor.

## 6. Basic Python concepts
- **Variables:** Names used to store values, e.g. `student_name = "Aditya"`.
- **Loops:** Repeat a block of instructions. A `for` loop can iterate over a sequence.
- **Functions:** Reusable blocks of code defined with `def`.
- **Lists:** Ordered collections that store multiple values, e.g. `subjects = ["AI", "Python"]`.
- **Conditions:** `if` and `else` let a program choose what to do based on a condition.
