# Student Grade Calculator — Python Mini Project

**Internship:** AI & ML Intern, Codomax Digital Solutions  
**Module:** 02 — Python Mini Project

## Overview
This beginner-friendly command-line program asks for a student's name and marks in Mathematics, Science, and English. It calculates the total, average, grade, and result status.

## Python concepts demonstrated
- Variables and data types
- Lists
- `for` and `while` loops
- Conditional statements
- Functions
- User input and output
- Input validation with `try` and `except`

## Requirements
Python 3.x. No external packages are needed.

## Run the program
```bash
python student_grade_calculator.py
```
If needed, use `python3` instead of `python`.

## Grade scale
| Average | Grade |
|---|---|
| 90–100 | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 50–59.99 | D |
| Below 50 | F |

## Example
Marks: 85, 90, 80  
Total: 255/300  
Average: 85.00%  
Grade: A

## Note
This is a learning project. It calculates results from the three marks entered during each run; it does not save student records.
