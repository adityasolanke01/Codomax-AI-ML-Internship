# Project Notes — Student Grade Calculator

## Objective
Create a Python program that calculates a student's total marks, average, grade, and result status.

## Algorithm
1. Ask the user for the student's name.
2. Ask for marks in three subjects.
3. Validate that every mark is numeric and between 0 and 100.
4. Calculate the total and average.
5. Use a function and conditions to find the grade.
6. Display the result.

## Test cases
| Marks | Average | Expected grade |
|---|---:|---|
| 90, 95, 100 | 95.00 | A+ |
| 80, 85, 75 | 80.00 | A |
| 70, 70, 70 | 70.00 | B |
| 60, 60, 60 | 60.00 | C |
| 50, 50, 50 | 50.00 | D |
| 30, 40, 45 | 38.33 | F |

## Conclusion
This project combines input/output, variables, lists, loops, functions, conditions, and input validation to solve a simple problem.
